【Dify 前端集成 - 快速开始指南】

✅ 问题已解决！你现在可以通过 Live Server 正常调用 Dify API

═══════════════════════════════════════════════════════════════

📋 五步快速启动：

1️⃣ 打开终端/命令行，进入项目文件夹

2️⃣ 安装依赖（只需要第一次）：
   npm install

3️⃣ 启动代理服务器：
   node proxy.js
   
   你会看到：
   ✅ Dify 代理服务器已启动
   📍 地址: http://localhost:3001

4️⃣ 在另一个终端启动 Live Server（保持代理运行）：
   npx live-server
   
   或用 VS Code 的 Live Server 扩展打开 index.html

5️⃣ 在网页中测试，向 AI 发送消息！

═══════════════════════════════════════════════════════════════

📝 做了什么改动：

✓ 创建了 proxy.js - 本地代理服务器
✓ 创建了 package.json - 项目依赖配置
✓ 修改了 index.html - 改为调用本地代理而不是直接调用 Dify
  - DIFY_BASE_URL 改为 http://localhost:3001/proxy
  - 移除了前端的 API Key 暴露
  - 改变了 API 端点 URL

═══════════════════════════════════════════════════════════════

🔍 工作原理：

浏览器 ──→ 本地代理服务器(3001) ──→ Dify API
           (处理 CORS + API Key)

代理服务器的好处：
✓ 解决浏览器 CORS 限制
✓ 保护 API Key（不在前端暴露）
✓ 可以添加更多安全功能

═══════════════════════════════════════════════════════════════

❓ 常见问题：

Q: 端口 3001 被占用了？
A: 修改 proxy.js 第 14 行的 PORT = 3001 为其他端口

Q: npm install 失败？
A: 运行 npm cache clean --force 再试一次

Q: Live Server 连接失败？
A: 确保 proxy.js 还在运行（检查终端窗口）

Q: 仍然无法连接？
A: 在浏览器按 F12 打开开发者工具，查看 Network 标签
